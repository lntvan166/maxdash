# Sharing findings (AGENTS.md "Throughout")

When the bike or the build shows something the docs do not say, tell the rider and offer to draft a report.

Bike report fields: bike model, year, market, dash part number (from cmd 83), phone and OS, what was sent
(command, flag, bytes), what the dash or bike did, logs or photos. Leave out serials, addresses and other
private data. Use `.github/ISSUE_TEMPLATE/bike-report.yml` and prefer a GitHub issue; ask before posting.
Only without a GitHub account: message the author on Telegram (see "Contact" in `README.md`).
