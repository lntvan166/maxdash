# Interview (AGENTS.md step 1)

Ask one at a time, in the rider's language; wait for each answer.

1. Which phone do you ride with: iPhone or Android (or both)?
2. Which computer can you use: Mac, Windows or Linux?
3. Which bike and year? The dash part number, if known.
4. Have you built an app or written code before?
5. What do you want on the dash that you can't get today?

Play back in two or three lines and ask if it is right. Then choose the build path from the table in
`AGENTS.md` step 2.
